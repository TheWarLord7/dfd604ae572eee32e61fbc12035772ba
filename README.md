## Temple Preservation Project - Backend

Backend currently only supports local llm access through ollama and soon api access will be added to it.

### Requirements
- Ollama
- NVIDIA CUDA TOOLKIT

Local LLM's Required:
- nomic-embed-text:v1.5
- gemma4:e4b

To Setup NVIDIA CUDA TOOLKIT follow this: https://markaicode.com/install-ollama-nvidia-gpu-cuda-support/
